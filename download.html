Which one

Installer, portable exe, or portable folder

Build Installs? Your data lives in Best for
🪄 DraconDex-Setup-<version>.exe Yes — pick a folder, get shortcuts %APPDATA%/DraconDex/, survives uninstall and updates Your own PC, the normal choice
🥾 DraconDex-Portable-<version>.exe No — one file, just run it novel-manager-data next to the exe A quick try, or a locked-down machine
🗂 DraconDex-<version>-win-x64.zip No — unzip and run DraconDex.exe novel-manager-data inside the folder USB sticks; the whole project travels with the folder
The portable builds are around 200–220 MB. That is Electron — the app bundles its own browser engine so it never needs a runtime installed, and never needs the network.
Verify

Check what you downloaded

Every release ships a checksums-sha256.txt covering the three Windows builds. Compare before you run anything. 

# PowerShell
Get-FileHash .\DraconDex-Setup-<version>.exe -Algorithm SHA256

# then compare against the matching line in checksums-sha256.txt
The builds are not code-signed. Windows SmartScreen will warn you the first time you run one. That warning is expected for an unsigned open-source build — checking the SHA-256 above is the real verification.
Android

The mobile port

A Flutter front-end lives in flutter/ in the app repository. It shares the desktop app's SQLite schema, so a database can move between the two — but it is developed independently and is currently behind on features.

ฝั่งมือถือยังพัฒนาตามหลังเวอร์ชัน Desktop อยู่ — ฟีเจอร์บางส่วนยังไม่มี

From GitHub Actions

APKs are not attached to releases. Run the Build Flutter APK workflow in the app repository and download the release-apks artifact.

Open the workflow

Build it yourself

Flutter SDK 3.44.4+ and the Android toolchain: 

cd flutter
flutter pub get
flutter build apk --release --split-per-abi

To move a project across: export novel-manager.db from the desktop app's data folder, copy it to the phone, then use Settings → Import Database in the Android app.

For developers

The source, as a package

The app is also published as @ldktc/dracondex on GitHub Packages. It is the app itself, not a library — there is nothing to import. Most people want the installer above. 

# ~/.npmrc — GitHub Packages needs a token even for public packages
@ldktc:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=YOUR_GITHUB_TOKEN
npm install @ldktc/dracondex

The token only needs the read:packages scope. Electron is a dev dependency, so running the app from that install still needs npm install in a full checkout.
